# System X-Ray: visual direction

Una mesa de inspección de arquitectura: tinta azul profundo, superficies blancas, verde lima para el flujo activo y notación de evidencia visible. Tipografía sans para narración y monospace exclusivamente en código y rutas. La demostración del flujo es el elemento visual central; no usa imágenes decorativas para simular diagramas técnicos.

La página presenta el propósito, un recorrido interactivo por una operación, herramientas opcionales y una instalación que se adapta al cliente. Se priorizan enlaces reales, controles accesibles, movimiento reducido y composición móvil sin desplazamiento horizontal de toda la página.
